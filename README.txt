BYMAR MAKEUP - GITHUB PAGES

1. Sube TODOS estos archivos a la raiz de tu repositorio (no dentro de otra carpeta):
   index.html
   halloween.html
   social.html
   novia.html
   infantil.html

2. En GitHub: Settings > Pages > Build and deployment > Deploy from a branch.
3. Branch: main. Folder: / (root).
4. Guarda y espera unos minutos.
5. Abre la URL que GitHub muestra en Settings > Pages.

IMPORTANTE: no abras el archivo HTML desde GitHub con el boton Code/README. La URL publica debe terminar en /ByMarMakeup/ y GitHub debe mostrar index.html desde la raiz.
